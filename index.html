A private AI for the files on your Mac.

Ask it to find anything in your files, or to brief you on one. It runs on your Mac, and nothing is uploaded.

curl -fsSL https://raw.githubusercontent.com/Suryanshgarg80/offwire/main/install.sh | bash
Paste into Terminal. Apple Silicon, macOS 14+, 8 GB. No admin password.

What it does

Nothing to importIt searches your whole home folder through Spotlight, then reads the best-matching files.
Briefs a file by reading itAsk for the key points of a file and it reads the file itself, then says how much it read.
Checks its own numbersEvery number in an answer is looked up in your files. One that isn't there is underlined.
Works with Claude, if you wantAn off-by-default switch lets the Claude desktop app search your files through Offwire.

What to know first

  • It's slow on an 8 GB Mac. An answer takes 10–20 seconds and a brief of a file 25–40. Follow-ups on the same file start in under a second.
  • It makes mistakes. The model is small, and on a long file it reads only part. Check anything that matters.
  • It reads your personal files, on your Mac only. Files named like passwords or keys are skipped, and you can turn whole-Mac search off.
  • It isn't signed by Apple yet, which is why it installs from Terminal. The install script is short and readable.
  • It sends nothing home. I only learn what you tell me.
